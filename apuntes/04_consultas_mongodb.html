Consultas y manejo de documentos en MongoDB

1 Introducción

MongoDB es una base de datos orientada a documentos que permite almacenar información en estructuras similares a JSON.

En este apartado se revisan las operaciones básicas para iniciar MongoDB localmente, crear bases de datos y colecciones, insertar documentos, realizar consultas y exportar resultados.

La finalidad no es únicamente aprender comandos, sino comprender cómo se recuperan y manipulan datos dentro de un modelo documental.

2 MongoDB y su estructura básica

MongoDB organiza la información de la siguiente manera:

Servidor
  │
  └── Base de datos
        │
        └── Colección
              │
              ├── Documento
              ├── Documento
              └── Documento

Por ejemplo:

curso_nosql
   │
   └── estudiantes
          │
          ├── Ana
          ├── Luis
          ├── Carlos
          ├── María
          └── Sofía

En este caso:

  • curso_nosql es la base de datos;
  • estudiantes es la colección;
  • cada estudiante se almacena como un documento.

3 Documentos en MongoDB

Un documento puede tener una estructura como:

{
  id: 1,
  nombre: "Ana",
  edad: 20,
  carrera: "Ciencia de Datos",
  redes_sociales: [
    "Instagram",
    "TikTok"
  ]
}

MongoDB utiliza internamente BSON, un formato relacionado con JSON que permite representar diferentes tipos de datos (MongoDB 2026).

Los documentos también contienen automáticamente un campo llamado _id.

Por ejemplo:

{
  _id: ObjectId("..."),
  id: 1,
  nombre: "Ana",
  edad: 20
}
NoteEl campo _id

MongoDB utiliza _id como identificador único de cada documento.

Si no se proporciona uno al insertar el documento, MongoDB lo genera automáticamente.

4 Iniciar MongoDB localmente

Antes de realizar consultas es necesario asegurarse de que el servidor de MongoDB esté en ejecución.

Durante la sesión podemos trabajar con tres terminales:

Terminal 1
   ↓
mongod
   ↓
mantiene activo el servidor

Terminal 2
   ↓
mongosh
   ↓
permite consultar y manipular la base

Terminal 3
   ↓
mongoexport
   ↓
permite exportar datos

5 Terminal 1: iniciar el servidor

En una primera terminal ejecutamos:

mongod

Esta terminal debe permanecer abierta mientras se esté trabajando con MongoDB.

Note¿Qué hace mongod?

mongod inicia el servidor de MongoDB.

Mientras este proceso permanezca activo, otras herramientas pueden conectarse a la base de datos.

La terminal quedará ocupada mostrando información del servidor.

Esto es normal.

WarningNo cerrar la Terminal 1

Si cerramos la terminal donde se está ejecutando mongod, el servidor se detendrá.

En ese caso, mongosh, MongoDB Compass y mongoexport ya no podrán conectarse al servidor local.

6 Terminal 2: abrir MongoDB Shell

Abrimos una segunda terminal y ejecutamos:

mongosh

mongosh permite conectarnos al servidor y ejecutar comandos de MongoDB.

El flujo será:

Terminal 1
mongod
   ↓
servidor MongoDB activo
   ↓
Terminal 2
mongosh
   ↓
consultas y operaciones

7 ¿Dónde se ejecutan los comandos?

Durante este tema trabajaremos principalmente de dos formas:

  1. mediante MongoDB Shell (mongosh);
  2. mediante MongoDB Compass.

Además, utilizaremos una tercera terminal para exportar datos mediante mongoexport.

8 Trabajo desde mongosh

Después de ejecutar:

mongosh

entramos al entorno de MongoDB Shell.

A partir de este momento podemos escribir comandos como:

show dbs
use curso_nosql
show collections
db.estudiantes.find()
db.estudiantes.insertOne({
  nombre: "Ana",
  edad: 20
})
NoteRegla sencilla

Los comandos como:

show dbs
use curso_nosql
show collections
db.estudiantes.find()

se ejecutan dentro de MongoDB Shell (mongosh).

9 Trabajo desde MongoDB Compass

MongoDB Compass es la interfaz gráfica para trabajar con MongoDB.

Para conectarnos al servidor local podemos utilizar:

mongodb://localhost:27017

Después podemos seleccionar:

curso_nosql
   ↓
estudiantes
   ↓
Documents

Dentro de la sección Documents encontramos el cuadro:

Filter

Ahí podemos escribir filtros para consultar los documentos.

Por ejemplo:

{
  nombre: "Ana"
}
WarningNo confundir mongosh con Compass

En mongosh:

db.estudiantes.find({
  nombre: "Ana"
})

En MongoDB Compass → Filter:

{
  nombre: "Ana"
}

En Compass no escribimos:

db.estudiantes.find()

porque la base de datos y la colección ya están seleccionadas en la interfaz.

10 Flujo general de trabajo

Podemos resumir el proceso de la siguiente manera:

Terminal 1
   │
   └── mongod
         │
         └── servidor activo
                │
                ├────────────────┐
                │                │
           Terminal 2       MongoDB Compass
                │                │
             mongosh           interfaz
                │                │
          comandos db.         Filter
                │
                │
           Terminal 3
                │
           mongoexport
                │
          JSON o CSV

11 Explorar las bases de datos

En la Terminal 2, dentro de mongosh:

Para consultar las bases de datos disponibles:

show dbs

Para seleccionar la base de datos del curso:

use curso_nosql

MongoDB mostrará un mensaje similar a:

switched to db curso_nosql

12 Crear una colección

En la Terminal 2, dentro de mongosh:

Podemos crear una colección llamada estudiantes:

db.createCollection("estudiantes")

Para consultar las colecciones disponibles:

show collections
Tip

MongoDB también puede crear una colección automáticamente cuando se inserta el primer documento.

Sin embargo, crearla explícitamente permite observar mejor la estructura de la base de datos.

13 Insertar un documento

En la Terminal 2, dentro de mongosh:

Para insertar un solo documento utilizamos:

insertOne()

Por ejemplo:

db.estudiantes.insertOne({
  id: 1,
  nombre: "Ana",
  edad: 20,
  carrera: "Ciencia de Datos",
  redes_sociales: [
    "Instagram",
    "TikTok"
  ]
})

Si la operación se realiza correctamente, MongoDB devuelve información sobre el documento insertado.

14 Insertar varios documentos

En la Terminal 2, dentro de mongosh:

Podemos insertar varios documentos utilizando:

insertMany()

Por ejemplo:

db.estudiantes.insertMany([
  {
    id: 2,
    nombre: "Luis",
    edad: 22,
    carrera: "Estadística",
    dispositivos: [
      {
        tipo: "celular",
        sistema: "Android"
      }
    ]
  },
  {
    id: 3,
    nombre: "Carlos",
    edad: 21,
    carrera: "Informática"
  },
  {
    id: 4,
    nombre: "María",
    edad: 23,
    carrera: "Ciencia de Datos",
    redes_sociales: [
      "Instagram"
    ]
  },
  {
    id: 5,
    nombre: "Sofía",
    edad: 20,
    carrera: "Estadística",
    redes_sociales: [
      "TikTok",
      "Facebook"
    ]
  }
])

Con esto tendremos documentos con estructuras diferentes dentro de la misma colección.

15 Consultar todos los documentos

15.1 En la Terminal 2, dentro de mongosh

db.estudiantes.find()

También puede escribirse:

db.estudiantes.find({})

El objeto vacío:

{}

indica que no estamos aplicando ningún filtro.

Por lo tanto, se devuelven todos los documentos.

15.2 En MongoDB Compass

En el cuadro Filter escribimos:

{}

y después aplicamos el filtro.

19 Operadores de comparación

MongoDB proporciona operadores para comparar valores.

Operador Significado
$gt mayor que
$gte mayor o igual que
$lt menor que
$lte menor o igual que
$ne diferente de

20 Mayor que

Queremos obtener estudiantes mayores de 20 años.

20.1 En la Terminal 2, dentro de mongosh

db.estudiantes.find({
  edad: {
    $gt: 20
  }
})

20.2 En MongoDB Compass

{
  edad: {
    $gt: 20
  }
}

21 Mayor o igual que

21.1 En la Terminal 2, dentro de mongosh

db.estudiantes.find({
  edad: {
    $gte: 20
  }
})

21.2 En MongoDB Compass

{
  edad: {
    $gte: 20
  }
}

22 Menor que

22.1 En la Terminal 2, dentro de mongosh

db.estudiantes.find({
  edad: {
    $lt: 22
  }
})

22.2 En MongoDB Compass

{
  edad: {
    $lt: 22
  }
}

23 Diferente de

23.1 En la Terminal 2, dentro de mongosh

db.estudiantes.find({
  carrera: {
    $ne: "Estadística"
  }
})

23.2 En MongoDB Compass

{
  carrera: {
    $ne: "Estadística"
  }
}

24 Consultar un intervalo

Podemos combinar operadores.

Por ejemplo, para buscar estudiantes entre 20 y 22 años:

24.1 En la Terminal 2, dentro de mongosh

db.estudiantes.find({
  edad: {
    $gte: 20,
    $lte: 22
  }
})

24.2 En MongoDB Compass

{
  edad: {
    $gte: 20,
    $lte: 22
  }
}

La condición significa:

edad >= 20
Y
edad <= 22

25 Consultas sobre arreglos

Un documento puede contener arreglos.

Por ejemplo:

{
  nombre: "Ana",
  redes_sociales: [
    "Instagram",
    "TikTok"
  ]
}

Queremos buscar estudiantes que utilicen Instagram.

25.1 En la Terminal 2, dentro de mongosh

db.estudiantes.find({
  redes_sociales: "Instagram"
})

25.2 En MongoDB Compass

{
  redes_sociales: "Instagram"
}

MongoDB identifica el valor dentro del arreglo sin necesidad de recorrerlo manualmente.

26 Consultas sobre objetos anidados

Supongamos:

{
  nombre: "Luis",
  dispositivos: [
    {
      tipo: "celular",
      sistema: "Android"
    }
  ]
}

Queremos encontrar documentos que tengan un dispositivo con sistema Android.

26.1 En la Terminal 2, dentro de mongosh

db.estudiantes.find({
  "dispositivos.sistema": "Android"
})

26.2 En MongoDB Compass

{
  "dispositivos.sistema": "Android"
}

La notación:

dispositivos.sistema

permite acceder a un campo dentro de una estructura anidada.

27 Condiciones múltiples

Cuando colocamos varias condiciones dentro del mismo objeto, MongoDB aplica normalmente una condición lógica AND.

Por ejemplo:

27.1 En la Terminal 2, dentro de mongosh

db.estudiantes.find({
  carrera: "Ciencia de Datos",
  edad: {
    $gte: 20
  }
})

27.2 En MongoDB Compass

{
  carrera: "Ciencia de Datos",
  edad: {
    $gte: 20
  }
}

Esto significa:

carrera = Ciencia de Datos
Y
edad >= 20

28 Operador $or

Cuando queremos que se cumpla una condición u otra utilizamos $or.

28.1 En la Terminal 2, dentro de mongosh

db.estudiantes.find({
  $or: [
    {
      carrera: "Ciencia de Datos"
    },
    {
      carrera: "Estadística"
    }
  ]
})

28.2 En MongoDB Compass

{
  $or: [
    {
      carrera: "Ciencia de Datos"
    },
    {
      carrera: "Estadística"
    }
  ]
}

La consulta devuelve estudiantes cuya carrera sea:

Ciencia de Datos
O
Estadística

29 Operador $in

Cuando queremos comparar un campo con varios valores posibles podemos utilizar $in.

29.1 En la Terminal 2, dentro de mongosh

db.estudiantes.find({
  carrera: {
    $in: [
      "Ciencia de Datos",
      "Estadística"
    ]
  }
})

29.2 En MongoDB Compass

{
  carrera: {
    $in: [
      "Ciencia de Datos",
      "Estadística"
    ]
  }
}

30 Operador $exists

El operador $exists permite comprobar si un campo está presente en un documento.

30.1 En la Terminal 2, dentro de mongosh

db.estudiantes.find({
  redes_sociales: {
    $exists: true
  }
})

30.2 En MongoDB Compass

{
  redes_sociales: {
    $exists: true
  }
}

Para consultar documentos donde el campo no existe:

30.3 En la Terminal 2, dentro de mongosh

db.estudiantes.find({
  redes_sociales: {
    $exists: false
  }
})

30.4 En MongoDB Compass

{
  redes_sociales: {
    $exists: false
  }
}
NoteEsquema flexible

$exists resulta especialmente útil en bases documentales porque no todos los documentos necesitan contener exactamente los mismos campos.

31 Contar documentos

En la Terminal 2, dentro de mongosh:

db.estudiantes.countDocuments({})

También podemos contar documentos que cumplan una condición:

db.estudiantes.countDocuments({
  carrera: "Ciencia de Datos"
})

32 MongoDB Compass

MongoDB Compass proporciona una interfaz gráfica para trabajar con bases de datos MongoDB.

Desde Compass podemos:

  • explorar bases de datos;
  • visualizar colecciones;
  • inspeccionar documentos;
  • aplicar filtros;
  • insertar documentos;
  • modificar información;
  • exportar documentos.

Una conexión local generalmente utiliza:

mongodb://localhost:27017
TipRecordatorio

MongoDB Compass no reemplaza al servidor.

Para conectarnos localmente, mongod debe estar activo en la Terminal 1.

33 MongoDB Shell dentro de Compass

MongoDB Compass también puede incluir acceso a un entorno de mongosh.

En ese caso sí podemos ejecutar comandos completos como:

db.estudiantes.find({
  edad: {
    $gt: 20
  }
})

La diferencia es:

Compass → Filter
      ↓
solo escribimos el objeto del filtro

Compass → mongosh
      ↓
podemos escribir comandos completos
