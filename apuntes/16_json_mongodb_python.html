2 JSON y Python

JSON significa JavaScript Object Notation.

Es un formato de texto que permite representar información mediante pares de clave y valor.

Aunque su nombre proviene de JavaScript, puede utilizarse con diferentes lenguajes de programación.

Python incluye una biblioteca llamada json, que permite trabajar directamente con este formato.

2.1 Recordemos la estructura de JSON

Observemos el siguiente documento:

{
    "codigo": "L001",
    "titulo": "Introducción a las bases de datos",
    "autor": "Ana López",
    "anio": 2024,
    "precio": 450,
    "disponible": true
}

Este documento representa un libro.

Cada propiedad tiene una clave y un valor.

Por ejemplo:

Clave Valor
codigo L001
titulo Introducción a las bases de datos
autor Ana López
anio 2024
precio 450
disponible true

En JSON podemos utilizar diferentes tipos de valores, como cadenas de texto, números, valores booleanos, arreglos y objetos.

2.2 Relación entre JSON y Python

Python utiliza los diccionarios para representar estructuras similares a los objetos JSON.

Por ejemplo:

libro = {
    "codigo": "L001",
    "titulo": "Introducción a las bases de datos",
    "autor": "Ana López",
    "anio": 2024,
    "precio": 450,
    "disponible": True
}

print(libro)

En este ejemplo creamos un diccionario que contiene la información de un libro.

Observa una diferencia importante:

  • En JSON utilizamos true y false.
  • En Python utilizamos True y False.

La biblioteca json se encarga de realizar las conversiones correspondientes.

Note

Importante

JSON es un formato para representar e intercambiar datos.

Un diccionario es una estructura de datos de Python.

Aunque sus estructuras son similares, no son exactamente lo mismo.

3 Procesamiento de JSON con Python

Comenzaremos utilizando Python sin conectarnos todavía a MongoDB.

Estos primeros ejercicios pueden realizarse en un archivo .py, en un entorno interactivo de Python o en Google Colab.

3.1 Importar la biblioteca JSON

Python incluye una biblioteca llamada json.

Para utilizarla escribimos:

import json

Esta biblioteca permite convertir información entre objetos de Python y documentos JSON.

3.2 Convertir un diccionario a JSON

Crearemos un libro utilizando un diccionario.

import json

libro = {
    "codigo": "L001",
    "titulo": "Introducción a las bases de datos",
    "autor": "Ana López",
    "anio": 2024,
    "precio": 450,
    "disponible": True
}

texto_json = json.dumps(
    libro,
    ensure_ascii=False,
    indent=4
)

print(texto_json)

La función json.dumps() convierte un objeto de Python en una cadena de texto con formato JSON.

En este ejemplo:

  • ensure_ascii=False permite conservar caracteres como acentos y la letra ñ.
  • indent=4 organiza el contenido utilizando sangrías.

El resultado es un texto JSON que representa la información del libro.

3.3 Convertir JSON a un diccionario

También podemos realizar la operación contraria.

import json

texto_json = """
{
    "codigo": "L002",
    "titulo": "Fundamentos de programación",
    "autor": "Carlos Pérez",
    "anio": 2022,
    "precio": 380,
    "disponible": false
}
"""

libro = json.loads(texto_json)

print(libro)
print(libro["titulo"])

La función json.loads() interpreta el texto JSON y lo convierte en un objeto de Python.

Después podemos acceder a sus valores mediante las claves del diccionario.

3.4 Diferencia entre dumps() y loads()

Función ¿Qué hace?
json.dumps() Convierte un objeto de Python a texto JSON
json.loads() Convierte texto JSON a un objeto de Python

Estas funciones son útiles cuando necesitamos intercambiar información entre aplicaciones.

4.2 Guardar la biblioteca en un archivo

Utilizaremos la función json.dump().

import json

with open(
    "biblioteca.json",
    "w",
    encoding="utf-8"
) as archivo:

    json.dump(
        libros,
        archivo,
        ensure_ascii=False,
        indent=4
    )

print("Archivo JSON guardado correctamente")

Este programa crea un archivo llamado biblioteca.json.

El archivo se guarda en el directorio de trabajo de Python.

4.3 Leer el archivo JSON

Ahora recuperaremos la información desde el archivo que acabamos de crear.

import json

with open(
    "biblioteca.json",
    "r",
    encoding="utf-8"
) as archivo:

    biblioteca = json.load(archivo)

print("Libros recuperados:", len(biblioteca))

La función json.load() lee la información de un archivo JSON y la convierte en objetos de Python.

En este caso recuperamos una lista de ocho libros.

4.4 Funciones para trabajar con JSON

Función Aplicación
json.dumps() Python a texto JSON
json.loads() Texto JSON a Python
json.dump() Guardar datos en un archivo JSON
json.load() Leer datos desde un archivo JSON

La diferencia principal es que las funciones sin s trabajan con archivos, mientras que las que terminan en s trabajan con cadenas de texto.

5 Consultar información JSON con Python

Una vez que tenemos los libros almacenados en una lista, podemos utilizar Python para recuperar información.

Durante los siguientes ejemplos utilizaremos la variable biblioteca obtenida en la sección anterior.

5.1 Recuperar todos los títulos

for libro in biblioteca:
    print(libro["titulo"])

El ciclo for recorre los libros y muestra sus títulos.

5.2 Recuperar libros disponibles

for libro in biblioteca:

    if libro["disponible"] == True:
        print(libro["titulo"])

La condición if permite seleccionar únicamente los libros disponibles.

5.3 Recuperar libros posteriores a 2023

for libro in biblioteca:

    if libro["anio"] > 2023:
        print(libro["titulo"])

Selecciona los libros cuyo año de publicación es mayor a 2023.

5.4 Recuperar libros de una categoría

for libro in biblioteca:

    if libro["categoria"] == "Bases de Datos":
        print(libro["titulo"])

Recupera los títulos de los libros que pertenecen a la categoría Bases de Datos.

5.5 Contar libros disponibles

total = 0

for libro in biblioteca:

    if libro["disponible"] == True:
        total += 1

print("Libros disponibles:", total)

Este programa utiliza un contador para calcular cuántos libros están disponibles.

5.6 Calcular el precio promedio

precios = []

for libro in biblioteca:
    precios.append(libro["precio"])

promedio = sum(precios) / len(precios)

print("Precio promedio:", round(promedio, 2))

El programa recupera los precios y calcula su promedio.

Note

Relación con XPath y XQuery

En el apunte anterior realizamos consultas sobre documentos XML.

Ahora estamos recuperando información similar, pero utilizando Python y una estructura JSON.

En ambos casos necesitamos identificar los campos, recorrer los registros y aplicar condiciones.

6 ¿Cómo se relaciona Python con MongoDB?

Hasta ahora hemos utilizado archivos JSON y listas de diccionarios.

Sin embargo, cuando desarrollamos una aplicación necesitamos almacenar información de manera persistente en una base de datos.

Para ello podemos utilizar MongoDB.

MongoDB es una base de datos documental que organiza información en colecciones de documentos.

Los documentos de MongoDB utilizan BSON, un formato binario que permite representar información similar a JSON y otros tipos de datos.

6.1 Estructura de MongoDB

Recordemos su organización:

MongoDB
   │
   └── Base de datos
          │
          └── Colección
                 │
                 ├── Documento
                 ├── Documento
                 └── Documento

Para nuestra práctica utilizaremos:

Componente Nombre
Base de datos curso_bdnr_python
Colección libros_apunte16
Documentos Libros de la biblioteca

6.2 ¿Qué es PyMongo?

PyMongo es la biblioteca oficial que permite conectar aplicaciones de Python con MongoDB.

Con ella podemos realizar operaciones como:

  • Insertar documentos.
  • Consultar información.
  • Aplicar filtros.
  • Actualizar registros.
  • Eliminar documentos.
  • Realizar conteos y ordenamientos.

Estas operaciones son similares a las que ya conocemos de MongoDB, pero ahora las ejecutaremos desde Python.

7 Preparación del entorno de trabajo

Podemos utilizar una instalación existente o iniciar un contenedor mediante Docker.

Abre la Terminal y ejecuta:

python3 --version

Este comando permite comprobar que Python está disponible.

Ejecuta:

python3 -m pip install pymongo pandas

Instalaremos dos bibliotecas:

  • pymongo: para conectar Python con MongoDB.
  • pandas: para organizar los resultados en tablas.

Si utilizamos Google Colab, la instalación se realiza en una celda:

%pip install pymongo pandas
Warning

Importante sobre Google Colab

Por esa razón, la dirección localhost dentro de Colab no corresponde a la computadora personal.

Para conectarnos a un MongoDB instalado en nuestra Mac utilizaremos Python ejecutándose localmente.

Si quisiéramos utilizar Colab para conectarnos a MongoDB, necesitaríamos un servidor accesible desde ese entorno, por ejemplo, una base de datos en MongoDB Atlas.

7.3 Comprobar MongoDB

Si ya tienes MongoDB funcionando localmente, puedes conservar la conexión y el puerto que utilizas normalmente.

Si no tienes un servidor disponible, puedes utilizar Docker.

Primero verifica los contenedores existentes:

Si no tienes un contenedor MongoDB para esta práctica, puedes crear uno:

Este comando crea un contenedor para la práctica.

El servidor MongoDB utiliza el puerto 27017 dentro del contenedor, mientras que desde nuestra computadora accederemos mediante el puerto 27018.

Para iniciar posteriormente el contenedor:

docker start mongo-python-lab

Para comprobar que está funcionando:

docker ps
Note

Importante

No debe exponerse directamente a internet sin configurar autenticación y las medidas de seguridad correspondientes.

8 Conectar Python con MongoDB

Ahora utilizaremos PyMongo para establecer una conexión con nuestro servidor.

8.1 Primera conexión

Crea un archivo de Python o abre un entorno interactivo.

Ejecuta:

from pymongo import MongoClient

cliente = MongoClient(
    "mongodb://localhost:27018/",
    serverSelectionTimeoutMS=5000
)

cliente.admin.command("ping")

print("Conexión correcta con MongoDB")

En este ejemplo:

  • MongoClient permite crear el cliente de conexión.
  • localhost indica que MongoDB se ejecuta en nuestra computadora.
  • 27018 es el puerto utilizado en nuestra práctica.
  • ping comprueba que el servidor responde.

Si el servidor está disponible, aparecerá el mensaje de conexión correcta.

8.2 Seleccionar una base de datos

Una vez establecida la conexión, seleccionaremos la base de datos.

db = cliente["curso_bdnr_python"]

print(db.name)

La variable db representa la base de datos con la que trabajaremos.

8.3 Seleccionar una colección

Ahora seleccionaremos la colección de libros.

coleccion = db["libros_apunte16"]

print(coleccion.name)

La variable coleccion permite realizar operaciones sobre los documentos de la biblioteca.

Note

Base de datos y colección

Seleccionar una base de datos o colección en Python no implica necesariamente que ya se haya almacenado información.

En MongoDB pueden crearse al insertar los primeros documentos.

9 Insertar documentos en MongoDB

Ahora utilizaremos los libros que creamos anteriormente en Python.

9.1 Preparar los documentos

Si continuamos utilizando la misma sesión de Python, podemos recuperar directamente la variable biblioteca.

Si abrimos una sesión nueva, primero debemos cargar el archivo JSON:

import json

with open(
    "biblioteca.json",
    "r",
    encoding="utf-8"
) as archivo:

    biblioteca = json.load(archivo)

De esta manera tendremos nuevamente los ocho libros.

9.2 Insertar o actualizar los libros de la práctica

Para evitar registros duplicados si ejecutamos varias veces el programa, utilizaremos el campo codigo para identificar cada libro.

for libro in biblioteca:

    coleccion.update_one(
        {"codigo": libro["codigo"]},
        {"$set": libro},
        upsert=True
    )

print("Biblioteca registrada correctamente")

Este código recorre los libros y realiza una operación por cada uno.

Si el libro ya existe, actualiza sus campos.

Si no existe, lo inserta.

El parámetro upsert=True permite realizar ambas acciones.

9.3 Contar documentos registrados

total = coleccion.count_documents({})

print("Documentos registrados:", total)

Esta consulta cuenta todos los documentos de la colección.

Si la colección estaba vacía antes de la práctica, tendremos ocho libros.

10 Primeras consultas con PyMongo

Ahora aprenderemos a recuperar información desde la base de datos.

10.1 Recuperar todos los documentos

for libro in coleccion.find():
    print(libro)

El método find() permite consultar documentos de una colección.

Cuando no especificamos filtros, recuperamos todos los registros.

10.2 Recuperar un solo documento

libro = coleccion.find_one()

print(libro)

El método find_one() recupera un documento que cumpla la consulta.

En este caso no especificamos condiciones.

10.3 Buscar un libro por código

libro = coleccion.find_one({
    "codigo": "L003"
})

print(libro)

Selecciona el libro cuyo código es L003.

10.4 Recuperar libros disponibles

for libro in coleccion.find({
    "disponible": True
}):

    print(libro["titulo"])

La consulta selecciona únicamente los documentos cuyo campo disponible contiene el valor True.

10.5 Buscar libros posteriores a 2023

for libro in coleccion.find({
    "anio": {"$gt": 2023}
}):

    print(libro["titulo"])

El operador $gt significa greater than y selecciona valores mayores al indicado.

10.6 Buscar por categoría

for libro in coleccion.find({
    "categoria": "Bases de Datos"
}):

    print(libro["titulo"])

Recupera los títulos de los libros de la categoría Bases de Datos.

11 Operadores de consulta en MongoDB

MongoDB utiliza operadores para expresar diferentes condiciones.

Algunos de los más utilizados son:

Operador Significado
$eq Igual a
$ne Diferente de
$gt Mayor que
$gte Mayor o igual que
$lt Menor que
$lte Menor o igual que
$in Coincide con algún valor de una lista
$and Cumple todas las condiciones
$or Cumple alguna de las condiciones

11.1 Consultar libros con precio mayor a 600

for libro in coleccion.find({
    "precio": {"$gt": 600}
}):

    print(libro["titulo"])

Selecciona los libros cuyo precio es mayor a 600.

11.2 Consultar libros en un intervalo de precios

for libro in coleccion.find({
    "precio": {
        "$gte": 400,
        "$lte": 600
    }
}):

    print(libro["titulo"])

Recupera los libros cuyo precio está entre 400 y 600, incluyendo ambos límites.

11.3 Combinar condiciones

for libro in coleccion.find({
    "disponible": True,
    "anio": {"$gt": 2023}
}):

    print(libro["titulo"])

Esta consulta selecciona los libros disponibles que fueron publicados después de 2023.

Cuando escribimos varias condiciones sobre campos diferentes, MongoDB las interpreta como condiciones que deben cumplirse conjuntamente.

11.4 Aplicar condiciones alternativas

for libro in coleccion.find({
    "$or": [
        {"categoria": "Bases de Datos"},
        {"categoria": "Ciencia de Datos"}
    ]
}):

    print(libro["titulo"])

Selecciona los libros que pertenecen a cualquiera de las dos categorías.

12 Seleccionar campos y ordenar resultados

En ocasiones no necesitamos recuperar todos los campos de un documento.

También podemos decidir el orden en el que queremos observar la información.

12.1 Recuperar solamente los títulos

for libro in coleccion.find(
    {},
    {"_id": 0, "titulo": 1}
):

    print(libro)

El segundo diccionario indica qué campos se devolverán.

En este ejemplo:

  • "titulo": 1 incluye el título.
  • "_id": 0 excluye el identificador interno de MongoDB.

12.2 Recuperar títulos y precios

for libro in coleccion.find(
    {},
    {
        "_id": 0,
        "titulo": 1,
        "precio": 1
    }
):

    print(libro)

La consulta devuelve únicamente el título y el precio de cada libro.

12.3 Ordenar libros por precio

from pymongo import ASCENDING

for libro in coleccion.find().sort(
    "precio",
    ASCENDING
):

    print(libro["titulo"], libro["precio"])

Ordena los libros desde el precio más bajo hasta el más alto.

12.4 Ordenar de mayor a menor

from pymongo import DESCENDING

for libro in coleccion.find().sort(
    "precio",
    DESCENDING
):

    print(libro["titulo"], libro["precio"])

Ordena los libros desde el más caro hasta el más barato.

12.5 Limitar la cantidad de resultados

for libro in coleccion.find().sort(
    "precio",
    DESCENDING
).limit(3):

    print(libro["titulo"], libro["precio"])

Ordena los libros por precio y recupera solamente los tres más caros.

13 Actualizar documentos desde Python

Además de consultar información, PyMongo permite modificar documentos.

13.1 Actualizar el precio de un libro

resultado = coleccion.update_one(
    {"codigo": "L001"},
    {"$set": {"precio": 480}}
)

print("Documentos modificados:", resultado.modified_count)

Esta operación busca el libro L001 y cambia su precio a 480.

El operador $set permite establecer un nuevo valor.

13.2 Modificar la disponibilidad

coleccion.update_one(
    {"codigo": "L002"},
    {"$set": {"disponible": True}}
)

Actualiza el libro L002 para indicar que está disponible.

13.3 Comprobar los cambios

libro = coleccion.find_one(
    {"codigo": "L002"}
)

print(libro)

Recupera el documento actualizado.

Note

Importante

Las operaciones de actualización modifican la información almacenada en MongoDB.

Los cambios permanecerán en la base de datos mientras no se eliminen o sustituyan los documentos.

Por eso debemos comprobar que los filtros identifican correctamente el registro que queremos modificar.

14 Insertar y eliminar un documento de prueba

Para comprender las operaciones de inserción y eliminación utilizaremos un documento temporal.

14.1 Insertar un documento

nuevo_libro = {
    "codigo": "L009",
    "titulo": "Libro de prueba",
    "autor": "Autor de ejemplo",
    "anio": 2026,
    "categoria": "Prueba",

}

resultado = coleccion.insert_one(nuevo_libro)

print("Documento insertado:", resultado.inserted_id)

El método insert_one() permite insertar un documento.

MongoDB agrega automáticamente un identificador _id cuando el documento no contiene uno.

Ejecuta esta inserción una sola vez para evitar repetir el registro de prueba.

14.2 Comprobar la inserción

libro = coleccion.find_one({
    "codigo": "L009"
})

print(libro)

Esta consulta permite comprobar que el documento está almacenado.

14.3 Eliminar el documento de prueba

resultado = coleccion.delete_one({
    "codigo": "L009"
})

print("Documentos eliminados:", resultado.deleted_count)

El método delete_one() elimina un documento que cumpla la condición.

En este caso eliminamos el libro temporal que creamos durante la práctica.

15 Relación entre mongosh y PyMongo

Las operaciones que realizamos con Python son similares a las que ya conocemos de mongosh.

Operación mongosh PyMongo
Consultar documentos db.libros.find() coleccion.find()
Consultar un documento db.libros.findOne() coleccion.find_one()
Insertar un documento db.libros.insertOne() coleccion.insert_one()
Actualizar un documento db.libros.updateOne() coleccion.update_one()
Eliminar un documento db.libros.deleteOne() coleccion.delete_one()
Contar documentos db.libros.countDocuments() coleccion.count_documents()

Aunque la sintaxis cambia ligeramente, las operaciones tienen objetivos similares.

La principal diferencia es que ahora las consultas forman parte de un programa de Python.

Esto permite desarrollar aplicaciones que se comuniquen automáticamente con MongoDB.

import pandas as pd

17.1 Comprobar la conexión

Después podemos comprobar la conexión desde Python:

cliente.admin.command("ping")

Si el comando responde correctamente, podemos continuar con las consultas.

Cuando terminemos las operaciones podemos cerrar el cliente.

cliente.close()

Esto libera los recursos utilizados por la conexión.
