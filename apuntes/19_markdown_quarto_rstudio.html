Creación de documentos con Markdown y Quarto desde RStudio

Bases de Datos No Relacionales

1 Introducción

Markdown es un lenguaje de marcado ligero que permite crear documentos mediante una sintaxis sencilla. Utiliza símbolos para organizar títulos, subtítulos, párrafos, listas, tablas, imágenes y expresiones matemáticas.

Quarto es un sistema de publicación que permite combinar Markdown con código ejecutable de R, Python y otros lenguajes para generar documentos en diferentes formatos, como HTML, PDF y Word.

En este apunte se aprenderá a crear documentos con Markdown y Quarto desde RStudio, incorporando elementos de formato, tablas, figuras, ecuaciones y bloques de código.

Durante el desarrollo del material se construirá progresivamente un documento titulado «Mi primer documento con Markdown y Quarto», cuyo contenido explicará las principales características y aplicaciones de estas herramientas.

Cada apartado incluye una explicación de la sintaxis y un ejemplo que se incorporará al documento. De esta manera, será posible observar cómo cambia su presentación después de renderizarlo.

Finalmente, se utilizará un conjunto de datos para generar estadísticas descriptivas y una visualización tridimensional, integrando los resultados en el mismo documento.

El objetivo principal es aprender a escribir, organizar y renderizar documentos reproducibles.

2 Preparación del proyecto

Antes de comenzar, es necesario descargar los archivos de trabajo que se utilizarán durante la elaboración del documento.

2.1 Descargar los archivos

Descarga el archivo comprimido desde el siguiente enlace:

Descargar archivos de trabajo

El archivo ZIP contiene:

  • mamut_datos.csv: conjunto de datos con coordenadas tridimensionales.
  • imagenes/mamut_referencia.png: imagen de referencia para practicar la inserción de figuras.

Una vez descargado el archivo:

  1. Descomprime Mi_primer_documento_Quarto.zip.
  2. Coloca la carpeta Mi_primer_documento_Quarto en el Escritorio de tu computadora.
  3. Abre la carpeta y comprueba que contenga los archivos proporcionados.

La estructura inicial será:

Mi_primer_documento_Quarto/
├── mamut_datos.csv
└── imagenes/
    └── mamut_referencia.png

Estos archivos se utilizarán posteriormente para incorporar imágenes, tablas y gráficas al documento.

2.2 Crear un proyecto en RStudio

Ahora se creará un proyecto de RStudio utilizando la carpeta descargada.

Abre RStudio y realiza lo siguiente:

  1. Selecciona File → New Project.
  2. Elige Existing Directory.
  3. Haz clic en Browse.
  4. Busca la carpeta Mi_primer_documento_Quarto en el Escritorio.
  5. Selecciona la carpeta.
  6. Haz clic en Create Project.

RStudio creará un proyecto dentro de la carpeta seleccionada.

Esto permitirá trabajar con los archivos mediante rutas relativas, sin necesidad de escribir su ubicación completa.

NotaCompatibilidad con Windows y macOS

Este procedimiento puede realizarse tanto en Windows como en macOS.

No será necesario modificar las instrucciones de lectura de archivos siempre que se conserve la estructura del proyecto.

Por ejemplo, la instrucción:

read.csv("mamut_datos.csv")

funcionará cuando el archivo CSV se encuentre en la carpeta principal del documento Quarto.

3 Crear nuestro primer documento Quarto

3.1 Crear un documento nuevo

Con el proyecto abierto en RStudio, selecciona:

File → New File → Quarto Document

Se abrirá la ventana New Quarto Document, donde se configurarán las características iniciales del archivo.

Completa las opciones de la siguiente manera:

Opción Configuración
Document Seleccionar
Title Mi primer documento con Markdown y Quarto
Author Nombre del estudiante
Format PDF
Engine Knitr
Use visual markdown editor Desmarcar

Finalmente, haz clic en Create.

Nota¿Por qué se utiliza el editor Source?

RStudio permite trabajar con documentos Quarto mediante dos modalidades:

  • Visual: permite aplicar formatos utilizando herramientas similares a las de un procesador de textos.
  • Source: permite escribir directamente la sintaxis de Markdown.

En este apunte se utilizará Source, porque el propósito es aprender a escribir las instrucciones de Markdown y observar cómo se transforman al renderizar el documento.

3.2 Guardar el documento

Guarda el archivo con el nombre:

mi_primer_documento.qmd

Es importante guardarlo dentro de la carpeta principal del proyecto.

La estructura será semejante a:

Mi_primer_documento_Quarto/
├── Mi_primer_documento_Quarto.Rproj
├── mi_primer_documento.qmd
├── mamut_datos.csv
└── imagenes/
    └── mamut_referencia.png

El archivo .Rproj corresponde al proyecto de RStudio, mientras que el archivo .qmd contendrá el documento que se desarrollará durante el apunte.

3.3 ¿Qué es un archivo .qmd?

Un archivo .qmd es un documento de Quarto que puede contener:

  • Texto escrito en Markdown.
  • Código ejecutable.
  • Tablas.
  • Imágenes.
  • Ecuaciones matemáticas.
  • Resultados generados automáticamente.

Al renderizarlo, Quarto transforma su contenido en el formato seleccionado.

4 Configuración inicial del documento

Un documento Quarto contiene principalmente dos partes:

  1. Encabezado YAML: establece las características generales del documento.
  2. Contenido: incluye texto, tablas, imágenes, ecuaciones y bloques de código.

4.1 Encabezado YAML

Al crear un documento Quarto, RStudio genera automáticamente un encabezado YAML y algunos ejemplos.

Elimina el contenido de ejemplo y coloca el siguiente encabezado al inicio de mi_primer_documento.qmd:

---
title: "Mi primer documento con Markdown y Quarto"
subtitle: "Elaboración de documentos reproducibles"
author: "Nombre del estudiante"
date: today
lang: es
format:
  pdf:
    toc: true
    toc-depth: 3
    number-sections: true
    fontsize: 11pt
    papersize: letter
    colorlinks: true
    geometry:
      - margin=2.5cm
execute:
  warning: false
  message: false
---

Sustituye Nombre del estudiante por tu nombre.

4.2 ¿Qué significa cada instrucción?

Instrucción Función
title Establece el título principal
subtitle Agrega un subtítulo
author Indica el nombre del autor
date: today Coloca automáticamente la fecha
lang: es Establece el idioma español
format: pdf Genera un documento PDF
toc: true Crea una tabla de contenido
toc-depth: 3 Incluye tres niveles de encabezados
number-sections: true Numera automáticamente las secciones
fontsize Define el tamaño base de letra
papersize Establece el tamaño del papel
colorlinks Activa los enlaces con color
geometry Configura los márgenes
warning: false Oculta advertencias de R
message: false Oculta mensajes de R
ImportanteImportante

El encabezado YAML debe conservar su estructura e indentación.

No deben utilizarse tabulaciones ni duplicarse opciones como format o execute.

Todas las configuraciones deben permanecer dentro de un único encabezado YAML.

5 Renderizar nuestro primer documento

Renderizar significa transformar el contenido de un archivo .qmd en un documento final, como HTML, PDF o Word.

En RStudio se puede utilizar el botón Render, ubicado en la parte superior del editor.

También es posible ejecutar el siguiente comando desde la Terminal del proyecto:

quarto render mi_primer_documento.qmd --to pdf

5.1 Instalación de LaTeX

Para generar documentos PDF, Quarto necesita una distribución de LaTeX.

Si no se dispone de una instalación, puede utilizarse TinyTeX.

Desde la Terminal de RStudio, ejecuta:

quarto install tinytex

Este comando se ejecuta en la Terminal, no en la Consola de R.

La instalación solamente debe realizarse una vez.

Después, vuelve a seleccionar Render.

5.2 Diferencia entre Consola y Terminal

En RStudio existen diferentes espacios de trabajo:

Herramienta Función
Consola Ejecutar instrucciones del lenguaje R
Terminal Ejecutar comandos del sistema operativo
Editor Source Escribir y modificar archivos .R y .qmd

Por ejemplo, para instalar un paquete de R se utiliza la Consola:

install.packages("scatterplot3d")

En cambio, para renderizar un documento mediante comandos se utiliza la Terminal:

quarto render mi_primer_documento.qmd

Durante este apunte se trabajará principalmente en el editor Source y se utilizará el botón Render para generar el PDF.

6 Títulos y subtítulos en Markdown

Markdown utiliza el símbolo # para definir encabezados.

El número de símbolos determina el nivel del título.

6.1 Sintaxis de los encabezados

# Título principal

## Subtítulo

### Encabezado de tercer nivel

#### Encabezado de cuarto nivel
Sintaxis Nivel
# Primer nivel
## Segundo nivel
### Tercer nivel
#### Cuarto nivel

Si se activa number-sections: true, Quarto numera automáticamente los encabezados.

6.2 Ejemplo: organizar nuestro primer documento

El primer apartado del documento presentará una introducción sobre Markdown y Quarto.

Agrega el siguiente contenido debajo del encabezado YAML de mi_primer_documento.qmd:

# Introducción

La elaboración de documentos académicos y técnicos requiere
herramientas que permitan organizar información, incorporar
resultados y mantener una presentación clara.

**Markdown** es un lenguaje de marcado ligero que utiliza
una sintaxis sencilla para estructurar documentos mediante
títulos, subtítulos, listas, tablas e imágenes.

Por su parte, **Quarto** permite combinar Markdown con código
ejecutable y generar documentos en diferentes formatos,
como HTML, PDF y Word.

## ¿Qué es Markdown?

Markdown utiliza símbolos para establecer la estructura
y el formato de un documento sin depender de herramientas
visuales de edición.

### Principales características

Entre sus características destacan la facilidad de escritura,
la organización del contenido y la compatibilidad con
diferentes herramientas de publicación.

#### Sintaxis sencilla

Para crear encabezados, listas y otros elementos,
Markdown utiliza símbolos como `#`, `*` y `-`.

## ¿Qué es Quarto?

Quarto es un sistema de publicación que permite elaborar
documentos reproducibles a partir de archivos `.qmd`.

### Documentos reproducibles

Un documento reproducible integra las explicaciones,
el código y los resultados dentro de un mismo archivo.

Esto permite actualizar automáticamente las tablas,
gráficas y resultados cuando se modifican los datos.

6.3 ¿Qué observar al renderizar?

Al seleccionar Render, Quarto organizará el contenido mediante encabezados de diferentes niveles.

Con la numeración activada, la estructura será semejante a:

1 Introducción

  1.1 ¿Qué es Markdown?

    1.1.1 Principales características

      1.1.1.1 Sintaxis sencilla

  1.2 ¿Qué es Quarto?

    1.2.1 Documentos reproducibles

La tabla de contenido incorporará los encabezados hasta el nivel establecido mediante toc-depth.

TipNumeración automática

No es necesario escribir manualmente los números de las secciones.

Quarto genera la numeración y la actualiza cuando se agregan o reorganizan encabezados.

7 Formato de texto en Markdown

Markdown permite modificar la presentación del texto mediante símbolos.

7.1 Negritas

Para escribir texto en negritas, se colocan dos asteriscos al principio y al final.

**Este texto aparece en negritas.**

7.2 Cursivas

Para escribir texto en cursivas, se utiliza un asterisco.

*Este texto aparece en cursivas.*

7.3 Negritas y cursivas

Ambos formatos pueden combinarse:

***Este texto aparece en negritas y cursivas.***

7.4 Texto tachado

Para tachar un fragmento se utilizan dos virgulillas:

~~Este texto aparece tachado.~~

7.5 Código dentro de un párrafo

Para destacar nombres de archivos, variables o funciones se utilizan acentos graves:

El archivo `mi_primer_documento.qmd` contiene
el código y el texto de nuestro documento.

7.6 Comparación de formatos

Sintaxis Resultado
**texto** texto
*texto* texto
***texto*** texto
~~texto~~ texto
`texto` texto

# Formato de texto en Markdown

10 Creación de tablas con Markdown

Markdown permite construir tablas utilizando el símbolo vertical |.

10.1 Sintaxis básica

| Formato | Descripción |
|:--|:--|
| HTML | Documento para navegador |
| PDF | Documento paginado |
| Word | Documento editable |

El resultado será:

Formato Descripción
HTML Documento para navegador
PDF Documento paginado
Word Documento editable

10.2 Alineación de columnas

Es posible controlar la alineación mediante los dos puntos:

| Izquierda | Centro | Derecha |
|:--|:--:|--:|
| A | B | 100 |
| C | D | 200 |
  • :-- alinea a la izquierda.
  • :--: centra el contenido.
  • --: alinea a la derecha.

10.3 Agregar títulos a las tablas

Quarto permite agregar una descripción a las tablas y asignarles un identificador.

| Formato | Extensión |
|:--|:--|
| HTML | .html |
| PDF | .pdf |
| Word | .docx |

: Formatos de salida de Quarto {#tbl-formatos}

El identificador {#tbl-formatos} permite realizar referencias automáticas.

10.4 Ejemplo: incorporar una tabla al documento

Agrega una nueva sección:

# Formatos de salida de Quarto

Quarto permite generar diferentes tipos de documentos
a partir de un mismo archivo `.qmd`.

Entre los formatos más utilizados encontramos:

| Formato | Extensión | Aplicación |
|:--|:--:|:--|
| HTML | .html | Publicación web |
| PDF | .pdf | Informes académicos |
| Word | .docx | Documentos editables |

: Principales formatos de salida de Quarto {#tbl-formatos}

La @tbl-formatos presenta los formatos de salida
más utilizados y algunas de sus aplicaciones.

Una ventaja de Quarto es que el contenido puede
mantenerse en un mismo archivo y generarse
en diferentes formatos.

10.5 ¿Qué observar al renderizar?

La tabla tendrá un título y numeración automática.

Además, la expresión @tbl-formatos será sustituida por la referencia correspondiente.

No será necesario escribir manualmente el número de la tabla.

11 Insertar imágenes

Markdown permite incorporar imágenes almacenadas dentro de un proyecto.

La sintaxis general es:

![Descripción de la imagen](ruta/imagen.png)

Para este ejemplo se utilizará la imagen de referencia del mamut que se encuentra dentro de la carpeta descargada.

La ruta es:

imagenes/mamut_referencia.png

11.1 Incorporar una imagen

En el documento escribe:

![Imagen de referencia del mamut](imagenes/mamut_referencia.png)

11.2 Cambiar el tamaño

Se puede establecer el ancho de una imagen mediante atributos de Quarto:

![Imagen de referencia del mamut](imagenes/mamut_referencia.png){width=70%}

La opción width=70% indica que la imagen ocupará el 70 % del ancho disponible.

11.3 Referencias automáticas

Para identificar una figura se utiliza un identificador que comience con fig-.

![Imagen de referencia del mamut](imagenes/mamut_referencia.png){#fig-mamut-referencia width=70%}

Posteriormente puede escribirse:

En la @fig-mamut-referencia se presenta
una imagen de referencia del mamut.

Quarto sustituirá la referencia por la numeración correspondiente.

# Incorporación de imágenes

14 Mostrar y ocultar código durante el renderizado

Quarto permite controlar qué elementos aparecen en el documento final.

14.1 Mostrar código y resultados

De manera predeterminada, Quarto muestra tanto el código como los resultados.

14.2 Ocultar código y mostrar resultados


14.5 Ocultar la salida textual

# Introducción

La elaboración de documentos académicos y técnicos requiere
herramientas que permitan organizar información, incorporar
resultados y mantener una presentación clara.

**Markdown** es un lenguaje de marcado ligero que utiliza
una sintaxis sencilla para estructurar documentos mediante
títulos, subtítulos, listas, tablas e imágenes.

Por su parte, **Quarto** permite combinar Markdown con código
ejecutable y generar documentos en diferentes formatos,
como HTML, PDF y Word.

## ¿Qué es Markdown?

Markdown utiliza símbolos para establecer la estructura
y el formato de un documento sin depender de herramientas
visuales de edición.

### Principales características

Entre sus características destacan la facilidad de escritura,
la organización del contenido y la compatibilidad con
diferentes herramientas de publicación.

#### Sintaxis sencilla

Para crear encabezados, listas y otros elementos,
Markdown utiliza símbolos como `#`, `*` y `-`.

## ¿Qué es Quarto?

Quarto es un sistema de publicación que permite elaborar
documentos reproducibles a partir de archivos `.qmd`.

### Documentos reproducibles

Un documento reproducible integra las explicaciones,
el código y los resultados dentro de un mismo archivo.

Esto permite actualizar automáticamente las tablas,
gráficas y resultados cuando se modifican los datos.

# Formato de texto en Markdown

El lenguaje **Markdown** permite aplicar diferentes
formatos mediante una sintaxis sencilla.

Por ejemplo, podemos utilizar *cursivas* para destacar
términos, **negritas** para enfatizar conceptos importantes
y ***ambos formatos*** cuando necesitamos un mayor énfasis.

También podemos identificar archivos y funciones mediante
formato de código, como `mi_primer_documento.qmd`
o `read.csv()`.

Una de sus principales ventajas es que el documento
conserva su contenido en un archivo de texto,
lo que facilita su edición y actualización.

## Características de Markdown

```{r}
coordenadas <- datos[c("x", "y", "z")]

resumen <- data.frame(
  Variable = names(coordenadas),
  Minimo = sapply(coordenadas, min),
  Maximo = sapply(coordenadas, max),
  Promedio = sapply(coordenadas, mean),
  Desviacion = sapply(coordenadas, sd),

)

knitr::kable(

  digits = 2,
  row.names = FALSE
)
```
