Consultas XML mediante XPath y XQuery

Bases de Datos No Relacionales

1 Introducción

En el apunte anterior aprendimos a representar información mediante documentos XML, utilizando elementos, atributos y estructuras jerárquicas.

También utilizamos Python para leer archivos XML y organizar su información en una tabla de datos.

Ahora aprenderemos a consultar directamente los documentos XML, sin necesidad de convertirlos previamente en tablas.

Para ello utilizaremos dos lenguajes:

  • XPath: permite localizar y seleccionar información dentro de un documento XML.
  • XQuery: permite realizar consultas más elaboradas, aplicar condiciones, ordenar registros y construir nuevos resultados.

Durante este apunte utilizaremos una biblioteca universitaria para comprender ambos lenguajes y practicar diferentes tipos de consultas.

Al finalizar podremos:

  • Recuperar elementos y atributos de un documento XML.
  • Comprender y escribir expresiones XPath.
  • Aplicar filtros y condiciones.
  • Utilizar funciones para contar y analizar información.
  • Construir consultas mediante XQuery.
  • Comprender las cláusulas FLWOR.
  • Ordenar y transformar información.
  • Construir nuevos documentos XML.

2 ¿Qué es XPath?

XPath significa XML Path Language.

Es un lenguaje que permite localizar información dentro de un documento XML mediante rutas.

Su funcionamiento se basa en la estructura jerárquica del documento.

Por ejemplo, consideremos el siguiente XML:

<biblioteca>
    <libro id="L001">
        <titulo>Introducción a XML</titulo>
        <autor>Ana López</autor>
    </libro>
</biblioteca>

La información está organizada de la siguiente manera:

biblioteca
    │
    └── libro
         │
         ├── titulo
         └── autor

Si queremos recuperar el título, podemos escribir:

/biblioteca/libro/titulo

Esta expresión indica la ruta que debemos seguir para localizar la información.

Podemos interpretarla así:

Parte Significado
/biblioteca Localiza el elemento principal
/libro Selecciona el elemento libro
/titulo Recupera el título
Note

Idea principal

XPath permite indicar dónde se encuentra la información dentro de un documento XML.

Podemos utilizarlo para recuperar elementos, atributos y valores, así como para aplicar condiciones.

3 Herramienta de trabajo: BXFiddle

Para realizar nuestras consultas utilizaremos BXFiddle, una herramienta en línea basada en BaseX.

Accede desde:

https://fiddle.basex.org/

No necesitamos instalar programas.

3.1 ¿Cómo funciona BXFiddle?

Para realizar una consulta necesitamos:

  1. Un documento XML que contiene información.
  2. Una expresión XPath o XQuery que indica qué información queremos recuperar.

BXFiddle permite escribir ambos componentes y observar los resultados.

Su distribución general es:

┌──────────────────────────────┬─────────────────────┐
│                              │                     │
│ EDITOR SUPERIOR              │                     │
│                              │                     │
│ Consulta XPath o XQuery      │                     │
│                              │     RESULTADOS      │
│ /biblioteca/libro            │                     │
│                              │                     │
├──────────────────────────────┤                     │
│                              │                     │
│ EDITOR INFERIOR              │                     │
│                              │                     │
│ Documento XML                │                     │
│                              │                     │
│ <biblioteca>                 │                     │
│    ...                       │                     │
│ </biblioteca>                │                     │
│                              │                     │
└──────────────────────────────┴─────────────────────┘

3.2 Preparar BXFiddle

Paso 1. Abre BXFiddle.

Paso 2. Identifica el editor superior izquierdo. Ahí escribiremos las consultas.

Paso 3. Identifica el editor inferior izquierdo. Ahí colocaremos el documento XML.

Paso 4. En el editor inferior, utiliza el tipo de contenido XML (Content-Type: xml).

Paso 5. Mantén la modalidad XQuery en el editor superior. Las expresiones XPath que utilizaremos pueden ejecutarse en este entorno.

Paso 6. Ejecuta la consulta y observa los resultados en el panel derecho.

Warning

Importante

Durante las prácticas recuerda:

  • Arriba: consultas XPath o XQuery.
  • Abajo: documento XML.
  • Derecha: resultados.

El documento XML debe estar configurado como información de entrada para que las consultas puedan utilizarlo.

3.3 Primera prueba

Copia el siguiente XML en el editor inferior:

<biblioteca>
    <libro id="L001">
        <titulo>Introducción a XML</titulo>
    </libro>
    <libro id="L002">
        <titulo>Bases de datos</titulo>
    </libro>
</biblioteca>

Ahora escribe esta consulta en el editor superior:

/biblioteca/libro

Esta expresión recupera los dos elementos libro.

Después cambia la consulta por:

count(/biblioteca/libro)

La función count() cuenta los elementos seleccionados.

En este ejemplo, el resultado es 2, porque la biblioteca contiene dos libros.

4 Preparación de la biblioteca XML

Para aprender XPath y XQuery utilizaremos nuevamente la biblioteca universitaria del Apunte 14.

Comenzaremos con una versión de cuatro libros, porque es más sencillo comprender las consultas con pocos registros.

Posteriormente trabajaremos con una biblioteca más grande.

4.1 Documento XML de trabajo

Sustituye el documento de prueba en BXFiddle por el siguiente:

<biblioteca>
    <libro id="L001">
        <titulo>Introducción a las bases de datos</titulo>
        <autor>Ana López</autor>
        <anio>2024</anio>
        <categoria>Informática</categoria>
        <disponible>true</disponible>
    </libro>

    <libro id="L002">
        <titulo>Fundamentos de programación</titulo>
        <autor>Carlos Pérez</autor>
        <anio>2022</anio>
        <categoria>Programación</categoria>
        <disponible>false</disponible>
    </libro>

    <libro id="L003">
        <titulo>Ciencia de datos con Python</titulo>
        <autor>María García</autor>
        <anio>2025</anio>
        <categoria>Ciencia de Datos</categoria>

    </libro>

    <libro id="L004">
        <titulo>Modelado de bases de datos</titulo>

        <anio>2023</anio>

        <disponible>true</disponible>

</biblioteca>

Cada libro contiene:

  • Un identificador.
  • Un título.
  • Un autor.
  • Un año de publicación.
  • Una categoría.
  • Un valor de disponibilidad.

biblioteca
│

│   ├── titulo

│   ├── categoria
│   └── disponible
│
├── libro (L002)
├── libro (L003)
└── libro (L004)
Note

Antes de continuar

Durante las siguientes consultas conservaremos este documento de cuatro libros.

Solamente cambiaremos las expresiones del editor superior de BXFiddle.

5 Primeras consultas con XPath

Comenzaremos recuperando información sin aplicar condiciones.

5.1 Recuperar el elemento raíz

/biblioteca

Selecciona el elemento principal del documento y todo su contenido.

5.2 Recuperar todos los libros

/biblioteca/libro

Selecciona los cuatro elementos libro contenidos en biblioteca.

5.3 Recuperar todos los títulos

/biblioteca/libro/titulo

Selecciona el elemento titulo de cada libro.

5.4 Recuperar los autores

/biblioteca/libro/autor

Recupera los autores de todos los libros. Si un autor aparece en varios registros, también aparecerá varias veces.

5.5 Recuperar los identificadores

/biblioteca/libro/@id

El símbolo @ permite seleccionar atributos. En este caso, recupera los identificadores de los libros.

5.6 Recuperar solamente el texto

/biblioteca/libro/titulo/text()

La expresión text() permite seleccionar los nodos que contienen el texto de los títulos.

5.7 Diferencia entre recuperar elementos y texto

Observemos estas expresiones:

/biblioteca/libro/titulo
/biblioteca/libro/titulo/text()

La primera recupera los elementos XML completos, incluyendo sus etiquetas.

La segunda selecciona únicamente los nodos de texto.

También podemos utilizar:

/biblioteca/libro/titulo/string()

Esta expresión obtiene el valor de texto de cada título.

Note

Elementos y valores

En XML podemos recuperar un elemento completo, incluyendo sus etiquetas, o solamente su contenido.

Esta diferencia será importante cuando utilicemos XQuery para construir nuevos resultados.

6 Operadores principales de XPath

XPath utiliza símbolos para navegar por las diferentes partes de un documento XML.

Operador Función
/ Indica una ruta o separa niveles
// Permite buscar elementos descendientes
@ Selecciona atributos
* Selecciona elementos de cualquier nombre
. Representa el nodo actual
.. Selecciona el nodo padre
[ ] Permite aplicar condiciones
text() Selecciona nodos de texto

6.1 Ruta completa

/biblioteca/libro/titulo

Selecciona los títulos siguiendo una ruta específica desde la raíz del documento.

6.2 Buscar elementos descendientes

//titulo

Busca elementos llamados titulo dentro del documento sin necesidad de escribir toda la ruta.

6.3 Recuperar atributos

//@id

Selecciona los atributos llamados id encontrados en el documento.

6.4 Seleccionar elementos sin especificar su nombre

/biblioteca/*

El símbolo * selecciona todos los elementos hijos de biblioteca.

6.5 Recuperar el elemento padre

/biblioteca/libro/titulo/..

El operador .. selecciona el elemento padre. Como los títulos están dentro de libro, recuperamos los libros.

7 Filtrar información mediante XPath

Hasta ahora recuperamos todos los elementos de una determinada clase.

Sin embargo, también podemos seleccionar solamente los registros que cumplen alguna condición.

Para ello utilizamos predicados, que se escriben entre corchetes [ ].

7.1 Recuperar libros disponibles

/biblioteca/libro[disponible = 'true']

Selecciona únicamente los libros que están disponibles.

7.2 Recuperar libros no disponibles

/biblioteca/libro[disponible = 'false']

Selecciona los libros cuyo valor de disponibilidad es false.

7.3 Recuperar libros posteriores a 2023

/biblioteca/libro[anio > 2023]

Selecciona los libros publicados después de 2023.

7.4 Recuperar libros anteriores a 2024

/biblioteca/libro[anio < 2024]

Selecciona los libros publicados antes de 2024.

7.5 Recuperar libros de Informática

/biblioteca/libro[categoria = 'Informática']

Selecciona los libros que pertenecen a la categoría Informática.

7.6 Recuperar libros de Ana López

/biblioteca/libro[autor = 'Ana López']

Selecciona los libros escritos por Ana López.

7.7 Combinar condiciones

Podemos utilizar and cuando necesitamos que se cumplan dos condiciones.

/biblioteca/libro[
    anio > 2023 and disponible = 'true'
]

Esta expresión selecciona los libros publicados después de 2023 que también están disponibles.

También podemos utilizar or cuando es suficiente que se cumpla alguna condición.

/biblioteca/libro[
    categoria = 'Informática'
    or categoria = 'Programación'
]

Selecciona los libros que pertenecen a cualquiera de esas dos categorías.

7.8 Recuperar solamente determinados campos

Podemos combinar un filtro con una ruta.

/biblioteca/libro[disponible = 'true']/titulo

Primero selecciona los libros disponibles y después recupera solamente sus títulos.

8 Funciones de XPath

Además de seleccionar elementos, XPath incluye funciones para contar y realizar operaciones con información.

8.1 Contar todos los libros

count(/biblioteca/libro)

Cuenta todos los libros registrados en la biblioteca.

8.2 Contar libros disponibles

count(
    /biblioteca/libro[disponible = 'true']
)

Cuenta únicamente los libros disponibles.

8.3 Contar libros no disponibles

count(
    /biblioteca/libro[disponible = 'false']
)

Cuenta los libros que no están disponibles.

8.4 Recuperar el primer libro

/biblioteca/libro[1]

Selecciona el primer libro del documento.

8.5 Recuperar el último libro

/biblioteca/libro[last()]

Selecciona el último libro.

8.6 Recuperar el año más reciente

max(/biblioteca/libro/anio)

Obtiene el año de publicación más alto.

8.7 Recuperar el año más antiguo

min(/biblioteca/libro/anio)

Obtiene el año de publicación más bajo.

8.8 Calcular el promedio de los años

avg(/biblioteca/libro/anio)

Calcula el promedio de los años de publicación.

8.9 Recuperar autores sin duplicados

distinct-values(/biblioteca/libro/autor)

Recupera los nombres de los autores sin repetir aquellos que aparecen en varios libros.

Note

Consideración

Estas funciones están disponibles en el entorno XPath/XQuery que utilizaremos con BXFiddle.

Aunque los años están escritos como texto dentro del XML, las funciones numéricas pueden interpretarlos como números cuando corresponde.

En XQuery también aprenderemos a convertir explícitamente esos valores.

9 ¿Qué es XQuery?

XPath nos permite recuperar información de un documento XML.

Sin embargo, en algunas situaciones necesitamos consultas que incluyan recorridos, condiciones, ordenamientos y construcción de nuevos resultados.

Para ello podemos utilizar XQuery (XML Query Language).

XQuery es un lenguaje diseñado para consultar y transformar información, especialmente documentos XML.

Una característica importante es que puede incorporar expresiones XPath.

9.1 Diferencia entre XPath y XQuery

Con XPath podemos recuperar los títulos:

/biblioteca/libro/titulo

Con XQuery también podemos hacerlo:

for $libro in /biblioteca/libro
return $libro/titulo

Ambas consultas recuperan los títulos de los cuatro libros.

La diferencia es que XQuery permite desarrollar consultas más elaboradas.

Por ejemplo, podemos recorrer todos los libros, seleccionar los disponibles, ordenarlos por año y construir un nuevo documento XML.

Note

Idea principal

XPath permite localizar y recuperar información.

XQuery puede utilizar XPath y agregar operaciones como recorridos, ordenamientos y construcción de nuevos resultados.

Ambos lenguajes se complementan.

10 Primeras consultas con XQuery

Continuaremos utilizando la biblioteca de cuatro libros.

10.1 Recuperar títulos

for $libro in /biblioteca/libro
return $libro/titulo

En esta consulta:

  • for permite recorrer los libros.
  • $libro es una variable que representa cada libro.
  • in indica qué elementos se recorrerán.
  • return indica qué información se devuelve.

10.2 Comprender el recorrido

Podemos representar el funcionamiento de esta manera:

Recuperar todos los libros
            │
            ▼
    Recorrer cada libro
            │
            ▼
      Obtener su título
            │
            ▼
    Mostrar los resultados

10.3 Recuperar los identificadores

for $libro in /biblioteca/libro
return $libro/@id

Recorre cada libro y devuelve su atributo id.

10.4 Recuperar únicamente el texto

for $libro in /biblioteca/libro
return string($libro/titulo)

Recorre los libros y recupera sus títulos como valores de texto, sin las etiquetas XML.

11 Expresiones FLWOR

Una de las estructuras más utilizadas en XQuery se conoce como FLWOR.

Su nombre se relaciona con cinco cláusulas:

Cláusula Función
for Recorre elementos
let Asigna valores a variables
where Aplica condiciones
order by Ordena resultados
return Define qué información se devuelve

No todas las consultas necesitan utilizar las cinco cláusulas.

11.1 Utilizar for y return

for $libro in /biblioteca/libro
return $libro/titulo

Esta consulta recorre todos los libros y devuelve sus títulos.

11.2 Agregar una condición con where

for $libro in /biblioteca/libro
where $libro/disponible = 'true'
return $libro/titulo

Recorre los libros, selecciona únicamente los disponibles y devuelve sus títulos.

11.3 Agregar un ordenamiento

for $libro in /biblioteca/libro
order by xs:integer($libro/anio) descending
return $libro/titulo

Ordena los libros desde el año más reciente hasta el más antiguo y devuelve sus títulos.

La expresión xs:integer() convierte el año a un número entero.

Si queremos ordenar del más antiguo al más reciente podemos utilizar ascending:

for $libro in /biblioteca/libro
order by xs:integer($libro/anio) ascending
return $libro/titulo

11.4 Combinar filtros y ordenamientos

for $libro in /biblioteca/libro
where $libro/disponible = 'true'
order by xs:integer($libro/anio) descending
return $libro/titulo

Esta consulta:

  1. Recorre los libros.
  2. Selecciona los disponibles.
  3. Los ordena por año.
  4. Devuelve sus títulos.

11.5 Utilizar let

La cláusula let permite almacenar temporalmente un valor en una variable.

let $total := count(/biblioteca/libro)
return $total

La variable $total almacena la cantidad de libros y después devuelve ese valor.

También podemos combinar for y let:

for $libro in /biblioteca/libro
let $titulo := string($libro/titulo)
return $titulo

En cada recorrido, $titulo almacena el texto del título correspondiente.

Note

Diferencia entre for y let

for permite recorrer los valores de una secuencia.

let asigna un valor o una secuencia a una variable.

Ambas cláusulas pueden utilizarse dentro de una misma consulta.

12 Construir nuevos resultados XML

Una de las ventajas de XQuery es que permite construir nuevos documentos XML utilizando información existente.

Por ejemplo, podemos generar un documento que contenga solamente los títulos y autores.

12.1 Construir elementos personalizados

for $libro in /biblioteca/libro
return
    <resultado>
        {$libro/titulo}
        {$libro/autor}
    </resultado>

Para cada libro se construye un elemento resultado que contiene su título y autor.

Las llaves { } permiten insertar expresiones XQuery dentro de los nuevos elementos XML.

12.2 Agrupar los registros en un documento

Si queremos que todos los resultados se encuentren dentro de un elemento raíz, podemos escribir:

<resultados>{
    for $libro in /biblioteca/libro
    return
        <libro>
            {$libro/titulo}
            {$libro/autor}
        </libro>
}</resultados>

Esta consulta construye un nuevo documento XML que agrupa los títulos y autores de todos los libros.

12.3 Construir un resumen general

<resumen>
    <total_libros>{
        count(/biblioteca/libro)
    }</total_libros>
    <disponibles>{
        count(
            /biblioteca/libro[disponible = 'true']
        )
    }</disponibles>
    <no_disponibles>{
        count(
            /biblioteca/libro[disponible = 'false']
        )
    }</no_disponibles>
</resumen>

Genera un documento XML con tres valores: total de libros, libros disponibles y libros no disponibles.

13 XPath y XQuery: principales diferencias

Característica XPath XQuery
Navegar por un documento XML Sí Sí
Recuperar elementos y atributos Sí Sí
Aplicar filtros Sí Sí
Contar registros Sí Sí
Utilizar funciones Sí Sí
Ordenar mediante FLWOR No Sí
Recorrer registros con for No Sí
Construir nuevos documentos XML No es su objetivo principal Sí

En general, utilizamos XPath cuando necesitamos localizar información directamente.

XQuery es especialmente útil cuando necesitamos recorrer registros, aplicar filtros, ordenarlos y construir nuevos resultados.

14 Errores frecuentes al utilizar XPath y XQuery

Durante las prácticas pueden presentarse errores relacionados con las rutas, los nombres de elementos o la sintaxis.

Problema Posible causa Solución
No aparecen resultados La ruta no coincide con el XML Revisar la estructura
Error de contexto El XML no está configurado como entrada Revisar BXFiddle
No se encuentra un elemento Nombre de etiqueta incorrecto Revisar mayúsculas y minúsculas
XQuery marca error Falta una instrucción o delimitador Revisar for, return y llaves
El ordenamiento es incorrecto Los valores se interpretan como texto Convertirlos a números
Aparecen etiquetas XML Se están recuperando elementos completos Utilizar string() para obtener texto

14.1 Ejemplo de una ruta incorrecta

Si escribimos:

/biblioteca/titulo

No recuperaremos los títulos porque titulo no es hijo directo de biblioteca.

La ruta correcta es:

/biblioteca/libro/titulo

14.2 Ejemplo de error en XQuery

Incorrecto:

for $libro in /biblioteca/libro
$libro/titulo

Falta la cláusula return.

Correcto:

for $libro in /biblioteca/libro
return $libro/titulo

14.3 Recomendación para identificar errores

Cuando una consulta no funcione, comienza por una ruta sencilla.

Primero:

/biblioteca

Después:

/biblioteca/libro

Finalmente:

/biblioteca/libro/titulo

De esta manera podemos identificar en qué parte de la consulta se encuentra el problema.
